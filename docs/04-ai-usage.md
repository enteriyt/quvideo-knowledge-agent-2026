# AI 辅助记录与贡献归属

## 本轮实际使用

本轮由 Codex 根据用户授权读取题目、选择第 3 题、设计并生成 Python 代码、合成资料、测试、样例生成脚本和交付文档。Codex 在本机执行离线验证，发现并修复子进程编码问题和通用检索词误召回问题。文档整理参考了本地 anti-defensive-writing 技能。

运行时模型接口与本轮开发助手是两个不同环节：开发助手生成源码；运行时实际采用本机 Qwen3-1.7B，通过 llama.cpp 的兼容 API 逐轮决策。Codex 下载官方运行程序和权重、核对 SHA-256、配置本地服务并执行真实验收，保留失败记录，改进格式约束、提示和空输入处理。GitHub 仓库由用户授权创建。

## 使用范围

| 交付内容 | 来源与核验 |
|---|---|
| src、tests、scripts | AI 生成，本机执行测试；代码待候选人逐段理解与审核 |
| data/documents.json | AI 编写的合成制度与产品资料，不代表真实企业规则 |
| docs、README | AI 编写，根据实际代码、测试结果核对 |
| examples 输出与 Trace | 本机脚本执行生成，离线使用 offline_mock，真实模型使用 live_model，输入校验注明未调用模型 |
| 个人经历、个人学习、独立贡献 | 未代写或虚构，需候选人本人确认补充 |

## 候选人需如实确认的内容

目前可观察到的用户参与为提出任务、提供链接、完成登录、授权生成材料和创建公开仓库。没有证据说明候选人已经亲自修改核心代码或独立验证全部结果，因此不能在提交时声称全部独立手写。

候选人应在提交前实际运行 README 命令，阅读冲突校验和模型循环，记录自己做过的修改、验证命令和结果。若没有个人代码修改，应明确写“代码由 AI 辅助生成，本人完成阅读、验证与取舍确认”，且只能在本人确实完成这些步骤后使用。

## 时间记录

本轮开发日期：2026-10-30（Asia/Shanghai）。起点为用户完成登录后要求生成交付物。本项目未启动可信的全程计时器，无法准确填写候选人实际投入；该数值由本人记录。测试耗时记录在 test-results.txt，单场景执行耗时记录在各 output.json，均不能替代人的投入时长。

## 密钥与隐私

未将 API 密钥、手机号或真实企业资料写入项目。环境示例中的密钥为空。GitHub 发布前需审核所有新增 live 输入和 Trace，确认仍只含合成数据。
