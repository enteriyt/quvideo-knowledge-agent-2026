# 开发复盘

本节记录本轮 AI 辅助开发中实际观察到的问题与取舍。候选人的个人学习体会由本人补充。

## 最难问题：检索相关不等于答案可靠

同一问题检索到两个不同期限时，直接选较新日期会隐藏规则冲突。实现将模型决策与结束校验分离：模型选择要读取什么，校验器要求相关来源已读，并在同范围规范值冲突时拒绝 answered。这样既保留动态检索与查证空间，也让错误的结束动作留下明确失败观察。

另一个实际问题来自扩大检索范围：给未知问题追加“制度、FAQ”导致报销文档被误召回。首轮测试暴露后，过滤通用词并验证原问题相关证据。该修改说明补充检索需要检查主题是否仍然一致。

## 取舍

原文式回答能直接核对引用，但可读性和多条件问答能力弱于自由摘要。小型词表召回易复现，但需在真实语料上增加语义检索。结构化规范值便于冲突检测，但由资料维护者承担元数据正确性。先完成可运行、可审计的核心链路，再用真实模型与更多变体测试决策质量。

## 下一步

1. 已配置真实本地模型并完成验收，下一步对每组重复运行，衡量状态和动作依据的稳定性。
2. 将“字幕准确率是多少”等资料内但证据不足的问题加入评测，细化 needs_input 与 answered 边界。
3. 增加真实文档切片、语义检索与召回评估，同时验证截断是否掩盖冲突。
4. 根据实际模型失败案例调整提示或校验逻辑，保留修改前后的可重复输入与结果。
